# Machine Learning

Exercices de Machine Learning.

| Dossier | Activité |
| --- | --- |
| BelgiqueStats | Statistiques sur les données belges |
| Classifier | Classification des données Heart Disease |
| Détecteur-de-langue | Analyse de textes et détection de langue |
| Heart-disease | Première analyse des données Heart Disease |
| imageDetector | Analyse et classification d'images |

Chaque activité possède sa branche. La branche `main` rassemble tous les sous-projets.
Les environnements virtuels et les réglages de l'IDE ne sont pas versionnés.
